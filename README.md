# Make10 アプリ (Make10 Web Application)

HTML、CSS、JavaScriptで作成したシンプルでモダンな **Make10（メイクテン）** ウェブアプリです。特別なインストールやサーバー不要で、ブラウザだけで手軽に遊ぶことができます。

---

## 🌟 主な機能

1. **遊ぶモード (ランダム問題)**
   - ランダムに選ばれた4つの数字タイルと、演算子（`+`, `-`, `×`, `÷`, `(`, `)`）を使って数式を自由に組み立てます。
   - 数字タイルは1回ずつ使用でき、演算子は何度でも（コピーして）使用可能です。
   - 「判定する」ボタンで、作成した数式が「10」になるかをその場でチェックできます。

2. **探すモード (自動解答検索)**
   - 好きな4つの数字を入力して「答えを探す」を押すと、10を作る数式の組み合わせを全パターン総当たり（即時計算）で瞬時にリストアップします。
