# Make 10

4つの数字を使って、四則演算で
**10を作れる数式を自動で検索するWebアプリ**です。

## 概要

4つの数字（0〜9）を入力すると、数字の並び順と四則演算の組み合わせを探索し、計算結果が10になる数式を検索します。

検索では単純に計算結果だけを比較するのではなく、**代数的に同じとみなせる式を正規化して重複を除外**します。

検索結果がある場合は、件数を表示したあと「解答を表示」ボタンから一覧を確認できます。

## ファイル構成

``` text
Make10/
├── index.html
├── style.css
├── solver.js
└── app.js
```

### index.html

画面のHTMLを担当します。

-   4つの数字を入力する欄
-   「答えを探す」ボタン
-   検索結果を表示する領域

JavaScriptは次の順番で読み込みます。

``` html
<script src="solver.js"></script>
<script src="app.js"></script>
```

`app.js`から`solveMake10()`を呼び出すため、**solver.jsを先に読み込む必要があります**。

### style.css

入力欄、ボタン、検索結果、解答一覧などの見た目を担当します。

### solver.js

Make 10の計算・検索処理を担当します。

主な処理は以下です。

-   `Fraction`：分数による正確な計算
-   `Node`：数式を構文木として管理
-   正規化処理：代数的に同じ式を同じキーへ変換
-   `permute()`：数字の並び替えを生成
-   `getExpressions()`：四則演算の構文木を生成
-   `solveMake10()`：10になる数式を検索し、重複を除外
-   表示用処理：検索結果を読みやすい数式へ整形

### app.js

画面操作を担当します。

主な処理は`searchAnswers()`です。

-   入力値の取得
-   0〜9の入力チェック
-   検索中メッセージの表示
-   `solveMake10()`の呼び出し
-   検索結果の表示
-   「解答を表示 / 解答を隠す」の切り替え

## 検索の仕組み

### 1. 数字の順番を試す

入力された4つの数字について、すべての順列を生成します。

### 2. 四則演算の組み合わせを試す

各数字の並びについて、`+`、`-`、`*`、`/`を使った数式の構文木を生成します。

### 3. 結果が10か確認する

各数式を`Fraction`で計算し、結果が10になるものだけを候補として残します。

分数をそのまま扱うため、浮動小数点誤差を避けて正確に比較できます。

## 重複除外

このアプリでは、単純に「計算結果が同じ」というだけでは数式を同一視しません。

一方、実装上の正規化ルールによって代数的に同じとみなせる式は、同じキーとして扱い重複を除外します。

### 加減算

加減算では項を展開して順序を整理します。

例えば、

``` text
3-(2-5-4)
```

は、

``` text
3-2+4+5
```

と同じ形として扱います。

### 乗算

入れ子になった乗算を展開し、因子の順序を整理します。

### `×1` と `÷1`

重複判定では`×1`や`÷1`を無視します。

例えば、

``` text
2*3+4
```

と

``` text
(2*3+4)*1
```

は同じものとして扱います。

ただし、4つの入力数字をすべて使った数式として表示する必要がある場合は、表示時に`×1`を戻します。

### `A / (B / C)`

``` text
A / (B / C)
```

は、

``` text
A * C / B
```

と同じ代数的構造として扱います。

## 表示

内部では`*`と`/`を使用し、画面では読みやすいように`×`と`÷`へ変換して表示します。

また、表示時には不要な括弧を減らし、できるだけ読みやすい数式に整形します。

## 使い方

1.  `index.html`をブラウザで開きます。
2.  4つの数字を入力します。
3.  **「答えを探す」**を押します。
4.  10を作れる数式が検索されます。
5.  解答がある場合は、**「解答を表示」**を押して一覧を確認します。
6.  もう一度押すと解答一覧を隠せます。

## 入力ルール

-   数字は4つ入力します。
-   入力できる値は`0〜9`です。
-   四則演算（`+`、`-`、`×`、`÷`）を使用します。
-   0による除算は解答候補から除外されます。

## 開発・保守

-   計算ロジックを変更：`solver.js`
-   画面操作を変更：`app.js`
-   見た目を変更：`style.css`
-   HTML構造を変更：`index.html`

計算ロジックとUIを分離することで、検索アルゴリズムを変更しても画面側への影響を小さくできます。

## 注意点

検索では数字の順列と数式の構造を大量に生成するため、入力によっては計算に時間がかかる場合があります。

また、正規化による重複除外は「数値として同じか」ではなく、実装しているルールに基づいて「代数的に同じとみなせるか」を判定しています。
